# Contributing

Bug fixes and focused features are welcome. Open an issue first for changes that
alter the addon protocol, configuration format, or playback behavior.

1. Branch from `main`.
2. Keep secrets and real Plex URLs out of fixtures, logs, commits, and screenshots.
3. Add regression tests for behavior changes.
4. Run the backend and frontend commands in the README.
5. Open a pull request using the repository template.

Use conventional, imperative commit subjects such as `Fix URL-safe legacy config`.
Maintainers may ask for a smaller PR when unrelated changes are combined.
